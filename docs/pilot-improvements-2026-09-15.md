## 데이터와 동작 범위

- 라이브러리는 기존 저장 방식을 유지한다. **로그인 계정별·현재 기기 로컬 저장**이며 다른 기기로 동기화되지 않는다. 화면에 이 범위를 안내한다. 템플릿 삭제는 이미 삽입된 워크아웃을 삭제하지 않는다.
- 카운트다운은 연결 수업의 기존 브리핑 → 시작 흐름을 변경한다. 로컬 시험 재생의 구간 타이머와 운동·휴식 종료 직전의 3초 효과음은 변경하지 않는다.
- 무압축 원본 사용은 새로 선택하는 이미지부터 적용된다. 이미 축소·압축되어 저장된 파일은 자동 복원되지 않는다.
- 로더는 기존 원본 URL과 비율 유지 디코딩을 사용한다. 디코딩 크기 상한 3840px은 유지한다. 배경 확대에 따른 원본 부족, TV 업스케일링 및 실제 1920/3820 비교 결과는 확보하지 못했다.
- 보정은 배경 크기·위치와 글자/타이머 안전 영역을 구분한다. 과도한 cover/확대는 이미지 일부를 자를 수 있다. TV 자체 오버스캔은 TV 설정도 확인해야 한다.
- 보정 미리보기의 흰 테두리는 배경 영역, 노란 테두리는 안전 영역이다. 패턴을 TV로 원격 송출하는 기능은 현재 범위에 포함하지 않았다.
- 이미지가 없으면 기존 기본 대기화면을 유지한다. 전체 배경 이미지 로딩이 모두 실패하면 기본 안내 문구를 제공한다.

## 매장에서 남은 확인

1. Android TV에서 대기 새로고침을 마우스, 방향키·확인 버튼으로 실행하고 네트워크 단절/복구 후 재시도한다.
2. 연결 수업을 0초·길어진 카운트다운으로 시작해 TV와 컨트롤러의 전환 시점을 비교한다. 수업 중 잠금 상태에서 터치·스와이프·뒤로 입력 후 길게 눌러 해제한다.
3. 문제가 발생한 1920/3820 원본과 저장된 파일의 실제 픽셀 크기를 비교한다. 같은 TV에서 원본 재선택 전후를 비교한다.
4. 서로 다른 TV에서 전체 보이기/꽉 채우기, 확대·위치·안전 여백을 저장하고 재접속 후 기기별 값이 유지되는지 확인한다. 이미지에 테스트 테두리를 넣어 가장자리와 비율을 비교한다.
5. 대기 이미지 교대·문구·로고·예약 수업·영업 종료 검은 화면을 실제 운영 시간대에서 확인한다.
