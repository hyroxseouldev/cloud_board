# 첫 수업 여정 (STA-99–103)

가입 전 가치 소개 → 예시 선택 → 이 기기에서 조작 → 내 수업 저장·편집 → 로컬 연습 → 센터·TV 준비 → 실제 TV 시작 응답 → 다음 수업 준비로 연결한다. 기존 센터 온보딩, 시작 템플릿, 슬라이드 시험 재생, 첫 수업 체크리스트를 확장한다.

## 목적별 진입과 복귀

| 의도 | 다음 화면 | 실제 저장 전 필요한 것 | 나중에·복귀 |
| --- | --- | --- | --- |
| 먼저 둘러보기 | `/explore`, 공개 fixture의 1분 체험 | 없음 | 홈 메뉴·로그인에서 다시 보기, 기기 로컬 선택 복원 |
| 오픈할 센터 준비 | 예시 선택 → 내 수업 편집 → 이 기기 연습 | 로그인, 기존 SMS/계정 소유자 검사 | 센터 상세 정보와 TV 연결은 뒤로 미룬다 |
| 운영 중인 센터 | 기존 센터 정보 → 명시적 체험 선택 → 첫 수업 준비 | 기존 센터·이용권·TV 등록/송출 권한 검사 | 저장된 단계와 다음 행동으로 복귀 |

‘내 수업 만들기’로 가입을 시작했다면 예시 선택과 목적을 인증·SMS 화면에 전달한다. 목적 선택 단계에서도 이 명시적 저장 의도를 이어 예시 가져오기로 복귀한다. SMS 화면의 ‘인증은 나중에 · 먼저 둘러보기’는 계정 저장 없이 공개 체험으로 돌아간다. 인증·예시 선택·로컬 연습은 무료 체험을 시작하지 않는다. 기존 체험 시작 버튼과 서버 검증을 그대로 사용한다.

## 데이터와 권한 경계

- 공개 경로는 `/explore`와 3종 fixture의 `/explore/play/{basics,interval,team}`만 허용한다. 계정·편집·실제 player·TV 경로는 기존 인증/온보딩 redirect를 유지한다. `starter`와 `purpose`는 열거된 값만 전달하며 임의 복귀 URL/워크아웃 ID를 수용하지 않는다. 인증 복원 대기 화면도 이 쿼리를 보존한다.
- 공개 화면은 로컬 fixture와 `SlideRehearsalController`만 사용한다. TV 세션·AI·체험 시작 API를 호출하지 않는다. 타이머는 화면 이동/백그라운드에서 멈추고 자동 소리를 끈다. 전환음은 사용자가 직접 시험한다.
- 원래 예시 시간은 유지한다. 데모만 운동 8초 + 휴식 4초 + 운동 8초를 3장, 총 60초로 줄인다. 사용자가 다음 슬라이드로 이동하며 조작하므로 실제 체험 소요 시간은 달라진다.
- `demo_*`: 기기 전용, 계정에 저장하지 않고 운영 이벤트를 보내지 않는다. `starter_*`: 기존에 가져온 예시, 기존 운영 집계 제외 규칙을 유지한다. `class_from_*`: 실제 수업용 일반 워크아웃, 실제 TV로 진행한 경우 정상 집계한다. 이름 변경으로 구분을 바꾸지 않는다.
- 내 수업 전환은 사용자 경로 안의 고정 ID와 기존 create-if-absent 서버 트랜잭션을 쓴다. 동시 요청·재시도는 이미 편집한 사본을 반환한다. 기존 예시는 보존한다. 다른 계정은 같은 예시로 독립적인 수업을 만든다.
- 탐색 선택·목적·완료·대기 중인 가져오기 의도는 SharedPreferences에 익명과 계정별로 분리한다. 로그인 시 명시적으로 전달한 예시/목적만 이어가며 다른 계정의 완료 기록을 복사하지 않는다. 개인정보나 운동 내용을 로컬 학습 이벤트에 넣지 않는다.
- `demo_started`, `demo_completed`, `demo_to_signup`은 해당 로컬 계정 범위에서 이름별 한 번만 기록한다. 익명 이벤트를 서버에 전송하거나 가입 후 계정과 자동 결합하지 않는다. `starter_to_owned`, `rehearsal_completed`는 기존 첫 수업 이벤트의 계정/센터/세션/이벤트 키로 중복 제거한다. 이 기록은 퍼널 계측의 기반이며 방문 횟수·전환율을 산출하는 분석 대시보드는 이번 범위가 아니다.
- 첫 수업 진행은 기존 계정/센터 범위로 저장한다. `rehearsedWorkoutId`는 TV ACK와 별도다. 모든 슬라이드를 끝까지 연습했을 때만 표시하며 중도 종료는 완료로 표시하지 않는다. `playedSessionId` 완료는 기존 실제 TV 시작 ACK 판정만 사용한다.
- 설문 목적/역할은 권한을 부여하지 않는다. 서버 규칙·SMS 정책·멤버십/초대 코치 모델은 변경하지 않는다.

## 화면 안내

저장된 수업이 없으면 둘러보기, 저장 직후에는 이 기기 연습, 연습 후에는 센터 정보/TV 준비를 추천한다. 확인한 TV가 온라인일 때 첫 재생을 추천하며 실제 시작 ACK 뒤에는 다음 수업 준비로 바뀐다. 전체 4단계는 펼쳐 볼 수 있고 숨긴 안내는 홈 메뉴에서 다시 연다.

빈 편집기는 수업·슬라이드·템플릿 관계를 설명하고 완성 예시를 연결한다. 첫 저장은 기존 서버 확인 이후에만 성공으로 표시한다. 편집 도움말은 닫고 다시 열 수 있으며 연습이나 TV 송출을 자동 실행하지 않는다. 저장하지 않은 편집 내용도 기기에서 미리 볼 수 있지만 저장 완료/첫 수업 연습 성공으로 기록하지 않는다.

PR 검토 이후 실제 신규 운영자 3명에게 첫 수업 관찰 테스트, 실제 SMS 취소/재진입, 물리 TV 송출, VoiceOver/TalkBack 검수를 수행한다. 위젯 테스트와 캡처는 이 실기기/사용자 검수를 대체하지 않는다. 설치 링크·플랫폼별 TV 준비 안내는 기존 STA-94 범위다.
