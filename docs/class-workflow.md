# 수업 브리핑과 TV 진행 흐름

수동 수업은 `수업 준비 → 브리핑 → 3초 카운트다운 → 운동 → 완료 → 대기` 순서로 진행한다.

- 워크아웃 재생을 누르면 이미지와 대상 디스플레이를 점검한다.
- `TV 브리핑 미리보기`는 세션을 만들거나 TV에 전송하지 않는다.
- `브리핑 화면 열기`는 선택한 TV에 워크아웃 전체 구성을 표시한다. 설명하는 동안 운동 시간은 흐르지 않는다.
- 강사가 `수업 시작 · 3초 카운트다운`을 누르면 서버 시각에 맞춰 모든 대상 화면이 시작한다.
- 운동 종료 후 TV는 완료 안내를 표시하고 약 5초 후 브랜드 대기 화면으로 복귀한다. 컨트롤러는 결과 화면을 유지한다.
- 기존 예약 재생은 지정 시각 자동 시작을 유지한다. 예약 전 자동 브리핑과 TV별 서로 다른 화면 역할은 별도 후속 범위다.

브리핑은 저장된 운동명, 본문, 운동 시간, 세트, 휴식과 브랜드 문구를 사용한다. TV는 한 페이지에 최대 3개 운동을 표시하며, 페이지가 많으면 12초 간격으로 순환한다. 컨트롤러에서는 전체 목록을 스크롤할 수 있다.

브랜드 설정의 대기 화면 미리보기와 TV 대기 화면은 같은 위젯을 사용한다. 기존 로고, 브랜드 색, 공지 이미지, 메시지, 다음 수업과 영업 종료 검은 화면 설정을 유지한다.

## 호환성 및 배포

세션에 선택 필드 `briefing`(기본 false)과 `startDelayMs`(기본 0)를 추가했다. 기존 세션은 그대로 읽힌다. 브리핑은 기존 `paused` 상태를 사용하므로 Realtime Database의 허용 상태 변경이 필요 없다.

새 흐름을 테스트하려면 컨트롤러와 웹/TV 앱 모두 이번 버전을 사용해야 한다. 이전 버전은 브리핑 필드를 알지 못하므로 일반 일시정지 화면으로 표시한다. 코드 변경만으로 설치된 TV 앱이나 호스팅된 웹앱이 갱신되지는 않는다.

## 매장 확인

1. TV 두 대를 연결하고 워크아웃의 브리핑 미리보기를 확인한다.
2. 두 대를 선택해 브리핑을 열고, 30초 기다려도 운동 시간이 소모되지 않는지 확인한다.
3. 시작 버튼을 눌러 두 TV의 카운트다운과 첫 운동 시작을 비교한다.
4. 일시정지, 재개, 이전/다음 운동 이동을 확인한다.
5. 재생 중 TV 하나를 재연결하고 현재 운동과 남은 시간으로 복구되는지 확인한다.
6. 마지막 운동이 끝나면 완료 안내 후 TV가 웰컴 화면으로 돌아오는지 확인한다.
7. 4개 이상의 운동, 긴 설명, 작은 휴대폰 화면, 기존 예약 재생을 확인한다.

새 브리핑은 실제 수업 시작 횟수에 포함하지 않으며, 시작 버튼으로 카운트다운을 실행할 때 `playback_started` 이벤트를 기록한다.
