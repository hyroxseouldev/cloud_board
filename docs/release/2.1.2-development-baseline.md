# CloudBoard 2.1.2 개발 기준점

2026-11-13 사용자 요청에 따라 이미지 용량 제한 변경분을 2.1.2 개발 기준점으로 확정한다.
기능 기준은 develop의 `85a80fc838344893cff0552b73ee08bfaece7500` (PR #169)이다.
앱 표시 버전은 2.1.2이며 pubspec의 기존 빌드 번호 8은 스토어 업로드 번호가 아니다.

- 운동별 이미지 100,000,000 bytes 제한과 초과 안내.
- 전체·슬라이드·카운트다운 이미지 용량 표시 및 중복 파일 단일 합산.
- saveWorkout의 실제 파일 메타데이터 검증과 거절 시 기존 수업 보존.
- 기능 검증 결과와 개발 서버의 saveWorkout 반영 기록은 PR #169를 따른다.
- 무료 계정의 총 보관량·일일 업로드 제한과는 별개다.

이 커밋은 개발 브랜치의 버전 및 소식 초안을 맞추는 기준점이다. 사용자의 개발 기점 요청에
따라 develop에만 반영하며 main 승격·배포 태그 생성·스토어 업로드·운영 소식 게시를 포함하지 않는다.
main 포함 여부를 요구하는 dev/v 태그는 이 기점에 만들지 않는다. 실제 배포를 진행할 때에는
main 통합, 버전·태그 일치 및 대상별 기존 검증/배포 절차를 따른다.
원본 작업 트리의 미커밋 작업은 이 기준점에 포함하지 않는다.
