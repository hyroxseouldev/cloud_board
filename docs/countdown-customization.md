# 카운트다운 표시 설정과 계정 기본값

관련 이슈: [CLY-13](https://linear.app/clyrdev/issue/CLY-13)
구현 브랜치: develop

## 사용 방법

워크아웃 편집 → 워크아웃 설정 → **수업 시작 카운트다운**에서 변경한다.

- 준비 시간: 0~60초 숫자 입력. 0초는 카운트다운 없이 시작한다.
- ‘준비하세요’와 운동 제목을 각각 숨기거나 표시한다.
- 숫자 형식(5 / 00:05), 크기(50~180%), 색상, 그림자를 설정한다. 형식 변경은 실제 시간을 바꾸지 않는다.
- 배경 오버레이의 표시, 색상, 불투명도를 설정한다. 끄면 선택한 카운트다운 이미지 또는 시작 슬라이드의 배경 이미지가 보인다. 이미지가 없으면 검은 바탕이다.
- 기존 카운트다운 전용 배경 이미지 선택/제거를 유지한다.
- ‘미리 재생’은 설정 화면 안에서만 동작한다. 실제 수업 시작이나 디스플레이 제어 명령을 보내지 않는다. 설정 변경이나 화면 닫기 시 미리보기 타이머를 정리한다.

워크아웃 저장 시 해당 워크아웃 설정을 저장한다.

## 계정 기본값의 범위

**내 기본값으로 저장**은 현재 카운트다운 설정을 계정에 별도로 저장한다. 기존 워크아웃이나 진행 중인 수업에는 소급 적용하지 않는다.

새 워크아웃을 만들 때 기본값을 복사한다. 이미 열어 편집 중인 초안에 기본값 변경을 자동으로 반영하지 않는다. 불러오기에 실패하면 재시도하거나 앱 기본 설정으로 새 워크아웃을 만들 수 있다.

기존 워크아웃에서 **내 기본값 가져오기**를 누르면 해당 초안의 카운트다운 설정만 교체한다. 운동 구성·시간·효과음 등 나머지 설정은 유지한다. 가져오기 되돌리기를 제공한다. 불러오는 중 카운트다운을 편집하거나 로그인 계정이 바뀌면 늦게 도착한 결과로 덮어쓰지 않는다.

## 저장과 호환성

- Firestore: `users/{uid}.countdownDefaults` (프로필 문서 merge)
- 기본값으로 저장하는 로컬 이미지: `users/{uid}/brand/countdown-defaults/{timestamp}`에 업로드한 URL을 저장한다.
- 워크아웃: 기존 countdownSeconds/backgroundColor/imageSource 필드와 새 countdownAppearance를 함께 저장한다.
- 재생 세션: 워크아웃 스냅샷에 표시 설정을 포함하므로 이후 계정 기본값 변경에 영향을 받지 않는다.
- 이전 워크아웃의 시간·배경 설정은 보존한다. 새 필드가 없으면 기존 문구 표시와 기본 크기를 사용한다. 이미지 배경의 기존 오버레이 불투명도도 보존한다.
- 기존 소유자 인증 규칙을 사용한다. 계정 삭제 절차가 사용자 문서와 사용자 소유 Storage 경로를 함께 처리한다.
- 이미지 URL은 기존 워크아웃에서도 참조할 수 있어 기본값 변경 시 이전 파일을 즉시 삭제하지 않는다.

- 실제 연결 디스플레이에서 변경한 표시 옵션 및 수업 시작 → 일시정지 → 재개 → 종료 확인.

## 함께 반영한 조정

- 키보드 내리기 버튼은 iOS·Android 공통으로 아이콘만 표시한다. 접근성 이름과 닫기 동작은 유지한다.
- 신규 워크아웃은 비프 1 테마를 사용하며 카운트다운·운동 시작·휴식 시작·종료 모두 비프 1을 적용한다. 기존 저장 설정은 유지한다.
- 재생 중인 슬라이드의 편집/진입 차단은 후속 요청으로 분리했다.
