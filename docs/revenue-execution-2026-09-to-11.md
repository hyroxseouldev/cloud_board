# CloudBoard 9~11월 수익화 실행안

작성 기준: 2026-09-18. 실행 기간: 9월 18일~11월 30일.
현재 유료 고객 수·매출·가용 시간이 확인되지 않아 유료 고객 0곳, 대표 1인, 주 20시간 투입을 가정한다. 아래 숫자는 실적이나 시장 평균이 아닌 실행 목표다. 기존 고객이 있으면 별도 기초 잔액으로 더한다.

## 1. 이번 3개월의 목표

9월에는 실제 수업에서 검증하고, 10월에는 8곳의 첫 결제를 받고, 11월 말에는 재결제를 포함해 유료 매장 15곳을 유지한다. 월 구독 청구액 585,000원과 초기 세팅 서비스 매출을 만든다. 3개월 안에 생활비를 모두 벌겠다는 계획은 아니다.

판매 문장: **“대표님이 쓰는 운동 프로그램을 TV 수업 화면으로 바꾸고, 휴대폰으로 순서와 시간을 제어할 수 있게 해드립니다.”**

초기 고객은 가까운 지역의 기능성 운동·그룹 PT 스튜디오 중 다음 조건을 갖춘 곳이다.

- 대표 또는 구매 결정권자와 직접 이야기할 수 있다.
- 주 3회 이상 그룹 수업을 하고 운동 순서·시간 안내에 반복 작업이 있다.
- TV·태블릿 등 검증 가능한 화면과 매장 네트워크가 있다.
- 자신의 운동 프로그램과 이미지가 있어 콘텐츠 공급을 기대하지 않는다.
- 한 계정에서 같은 수업을 1~3개 화면으로 진행하면 충분하다.

첫 후보는 지인·기존 파일럿의 소개 → 방문 가능한 인근 매장 → 관련 매장 공개 사업 문의 채널 순으로 찾는다. 지역은 사용자가 이동 가능한 범위로 정한다. 대형 체인 본사와 기기 구매부터 필요한 매장은 후순위다.

## 2. 팔 상품은 두 개

| 상품 | 제안 고객 총액 | 납품 범위 |
|---|---:|---|
| 월 구독 | 매장당 월 39,000원 | 단일 운영 계정, 같은 수업을 검증된 디스플레이 최대 3대에 표시, 현재 편집·타이머·수업 제어 기능 |
| 선택형 초기 세팅 | 149,000원 1회 | 고객 제공 프로그램 3개 입력, 배경·색상 적용, 원격 연결 및 교육 60분, 수정 1회; 전체 작업 상한 2시간 |

가격은 부가세 포함 표시안이다. 실제 판매 전 청구·증빙 기준을 확정한다. TV·태블릿 등 장비와 현장 방문은 위 가격에 포함하지 않는다. 모든 고객에게 직접 설치할 수 있는 안내와 기본 원격 연결 지원 20분을 제공한다. 초기 세팅 구매가 구독의 필수 조건은 아니다.

14일 무료 체험은 실제 첫 연결을 마치고 시작 동의를 받은 날부터 진행한다. 카드 없이 시작하고 자동 유료 전환하지 않는다. 기존 파일럿의 무료 조건은 별도 협의한다. 첫 3개 파일럿은 사례 확보를 위해 세팅비를 면제하며, 유료 세팅 매출 목표에서 제외한다.

세팅 진행 전 고객의 자료·호환 기기·범위를 확인하고, 검수 완료 시 청구하는 방식으로 시작한다. 3개를 넘는 프로그램이나 방문 작업은 별도 견적을 합의하기 전 수행하지 않는다. 운동 처방·영상 제작은 제공 범위가 아니다.

첫 제안은 39,000원으로 통일한다. 첫 고객에게 평생 할인이나 무제한 맞춤 개발을 약속하지 않는다. 세팅 149,000원은 아직 검증하지 않은 가격 가설이며 실제 구매율을 따로 측정한다.

## 3. 판매 전 확인할 상태

9월 17일 구현 기록에 재생·잠금 복귀·기기 등록 개선이 있지만 실제 Android 태블릿+디스플레이 및 iPad의 일부 검증은 남아 있다. 코드 반영을 현장 통과로 간주하지 않는다. 결제·구독은 기존 문서에서 기획 단계였으므로 운영 가능 여부를 먼저 확인한다.

첫 유료 전환 전 완료 조건:

- [ ] 지원할 기기 조합을 실제로 정하고 설치 링크부터 첫 수업까지 확인한다.
- [ ] 기존 파일럿 운영서 기준으로 실제 60분 수업 10회에서 치명적 타이머·슬라이드 오류 0건을 기록한다.
- [ ] 화면 잠금·앱 재실행·네트워크 단절과 복구를 확인한다. 실패하면 해당 환경 판매를 미룬다.
- [ ] 첫 번째 수업은 함께 진행하고 두 번째 수업은 코치가 혼자 시작한다.
- [ ] 가격·제공 범위·문의 창구·해지·환불·이용 종료 조건을 한 장으로 안내한다.
- [ ] 결제 성공·실패·취소·중복 결제·만료와 앱 이용 권한을 검증한다. 구독 만료로 진행 중인 수업을 끊지 않는다.
- [ ] 선택한 판매 방식과 스토어 배포 방식의 결제 정책을 확인한다. 앱 안에 임의로 외부 결제 링크를 넣지 않는다.

결제가 늦으면 시연·체험 모집은 계속하되 결제 약속을 매출로 기록하지 않는다. 수동 청구도 해당 배포·판매 방식에서 가능한지 확인한 뒤 금액·이용 기간·갱신 방식을 명시하고 운영한다. 확인이 끝나지 않으면 첫 매출 일정을 미룬다.

## 5. 매주 반복할 업무

주 20시간 배분: 신규 영업·후속 연락 6시간, 시연·연결 4시간, 지원·세팅 4시간, 안정성·결제 개발 4시간, 기록·사례 정리 2시간. 개발 문제가 4시간을 넘으면 신규 체험 수를 줄이고 일정을 재산정한다. 지원 및 유료 세팅이 몰리는 주에는 새 설치를 다음 주로 예약한다.

- 월요일: 이번 주 후보 25곳 선정, 기존 고객 이용 확인, 체험 종료 예정 정리.
- 화~목요일: 하루 신규 연락 5곳씩, 예정된 시연·연결 실행.
- 금요일: 추가 신규 연락 10곳, 체험 고객 후속 확인, 결제·갱신·지원 시간 기록.
- 토요일 또는 매장과 정한 시간: 실제 수업 1회 관찰, 반복 문제 1개 해결.

신규 연락은 무작위 대량 발송이 아니라 매장 상황을 확인한 개별 접촉이다. 공개된 사업 문의 채널과 소개를 우선 사용하고 거절한 곳은 중단한다. 주간 숫자보다 대표와의 실제 대화 수를 우선한다. 연휴·수업 시간에는 응답률을 가정하지 말고 미팅 시간을 먼저 합의한다.

## 6. 그대로 사용할 영업 문구

### 첫 연락

> 안녕하세요, 대표님. 그룹 운동 수업용 화면 도구 CloudBoard를 만드는 [이름]입니다. [매장명]에서 [확인한 그룹 수업]을 운영하시는 걸 보고 연락드렸습니다. 대표님이 쓰시는 운동 프로그램과 타이머를 TV에 띄우고 휴대폰으로 진행을 제어하는 도구입니다. 현재 수업 순서와 시간을 어떻게 안내하고 계신가요? 필요하시면 실제 작동 영상과 10분 시연을 보여드리고 싶습니다.

발신자 이름은 실제 사용하는 이름으로 바꾼다. 매장을 확인하지 않고 대괄호 부분을 꾸며 쓰지 않는다.

### 관심을 보이면

> 기존에 사용하시는 프로그램 하나로 시연해드릴게요. 사용하시는 TV·태블릿 기종을 먼저 확인하고, 연결 후 14일간 실제 수업에서 써보실 수 있습니다. 이후 계속 이용하시면 매장당 월 39,000원이고 자동으로 유료 전환되지는 않습니다. 직접 설정하셔도 되고, 프로그램 3개 입력과 원격 교육을 맡기시면 세팅비 149,000원이 별도입니다.

### 10분 시연 순서

1. 2분: 현재 수업 안내 방식과 가장 번거로운 순간을 묻는다.
2. 4분: 고객 프로그램 하나를 화면에 띄우고 시작·정지·다음 이동을 보여준다.
3. 2분: 코치가 직접 한 번 조작한다.
4. 2분: 호환 기기 확인, 가격 안내, 첫 수업 날짜를 정한다.

### 체험 관리

| 시점 | 질문 또는 행동 |
|---|---|
| 시작일 | 첫 연결, 첫 수업, 종료일과 가격 안내. 기존 준비 시간을 기록 |
| 3일째 | “직접 몇 번 쓰셨나요? 다음 수업에도 쓸 예정인가요?” 사용이 없으면 원인부터 확인 |
| 7일째 | “없어지면 다시 불편해질 부분이 있나요?” 수업 횟수와 지원 시간을 기록 |
| 11일째 | “체험 종료일은 ○일이고 이후 월 39,000원입니다. 계속 사용하실지 ○일까지 알려주실 수 있을까요?” |
| 14일째 | 결제 또는 미전환을 확정. 응답 없이 자동 과금하지 않음 |
| 결제 후 7일 | 실제 사용과 장애 여부 확인, 만족하면 소개 1곳 요청 |
| 갱신 전 | 다음 이용 기간과 금액 안내, 이용 감소 원인 확인 |

“무료로 조금 더” 요청은 설치·장애 때문에 못 쓴 경우에 한해 이유와 새 종료일을 기록해 한 번 조정한다. 구매 결정이 없다는 이유만으로 체험을 무기한 늘리지 않는다.

### 자주 나오는 반응

- “기존 타이머로 충분해요.” → “그럼 바꿀 이유가 크지 않을 수 있겠네요. 운동 설명이나 순서 안내도 지금 방식이 편하신가요?” 문제 없으면 종료.
- “다른 무료 서비스가 있어요.” → “직접 비교해보셔도 좋습니다. 대표님 프로그램을 만드는 과정과 실제 수업 조작이 더 편한지로 판단해주세요.”
- “회원 관리도 되나요?” → “현재는 수업 화면과 진행 제어를 제공합니다.” 현재 없는 기능을 계약 조건에 넣지 않음.
- “TV를 사야 하나요?” → 기존 장비 호환성을 먼저 확인. 장비 구매가 먼저 필요하면 당장 판매 대상에서 후순위.

## 7. 숫자로 보는 판매 경로

9~11월 기본 활동 목표: 서로 다른 후보 200곳에 첫 접촉 → 양방향 대화 60곳 → 시연 40곳 → 실제 시작 체험 33곳 → 첫 결제 16곳 → 11월 말 유료 유지 15곳.

이는 관측된 전환율이 아닌 작업량 가설이다. 접촉 200곳 중 16곳이 결제하는 8% 가정이며, 소개가 적거나 연락 채널이 맞지 않으면 달성하지 못할 수 있다. 체험 33곳 중 말일 기준 아직 14일이 지나지 않은 곳을 실패로 계산하지 않는다. 체험 전환율은 종료한 코호트끼리 비교한다.

10월 8곳 첫 결제, 11월 기존 8곳 중 7곳 갱신+신규 8곳=15곳을 기본 시나리오로 둔다. 아래 계산은 각 청구가 해당 월에 정상 수납된다는 단순 모델이다. 실제 매출표는 고객별 결제일·환불·미수에 따라 갱신한다.

| 기본안 | 9월 | 10월 | 11월 | 합계 |
|---|---:|---:|---:|---:|
| 신규 유료 매장 | 0 | 8 | 8 | 16 |
| 해당 월 갱신 매장 | 0 | 0 | 7 | 7 |
| 월말 유료 유지 매장 | 0 | 8 | 15 | — |
| 구독 수납 목표 | 0원 | 312,000원 | 585,000원 | 897,000원 |
| 유료 세팅 건수 | 0 | 3 | 4 | 7 |
| 세팅 수납 목표 | 0원 | 447,000원 | 596,000원 | 1,043,000원 |
| 총 수납 목표 | 0원 | 759,000원 | 1,181,000원 | **1,940,000원** |

월말 반복 청구 규모는 15×39,000=585,000원이다. 세팅비는 다음 달 반복 매출에 포함하지 않는다. 모든 금액은 고객 총 결제액 기준이며 세금·서버·결제 수수료·교통비·본인 인건비를 차감한 순이익이 아니다.

| 시나리오 | 10월 유료 | 11월 유료 | 11월 월 반복 청구액 | 3개월 유료 세팅 | 3개월 총 수납 모델 |
|---|---:|---:|---:|---:|---:|
| 보수적 | 3곳 | 5곳 | 195,000원 | 2건 | 610,000원 |
| 기본 | 8곳 | 15곳 | 585,000원 | 7건 | 1,940,000원 |
| 확장 | 15곳 | 30곳 | 1,170,000원 | 12건 | 3,543,000원 |

보수적·확장 모델도 9월 수납 0원, 각 월 유료 수만큼 한 번 수납을 가정한다. 확장안은 기본안보다 소개·전환·운영 효율이 높아야 하므로 기본 영업량으로 보장되는 결과가 아니다.

월 구독 총액 100만원에는 26곳, 300만원에는 77곳이 필요하다. 이번 기간에 더 큰 현금 수입이 필요하다면 월 39,000원 SaaS만으로는 부족하다. 세팅 수요와 납품 시간을 검증한 후 서비스 단가를 재설계해야 한다.

## 8. 수익을 남기는 운영 기준

영업 현금 예산은 3개월 합계 30만원 상한으로 시작한다. 지출 전에 항목을 기록하고, 이동·시연 등 직접 고객 확보에 우선 사용한다. 서버·결제·기존 운영비는 별도 기록한다. 유료 광고와 하드웨어 재고 구매는 이 기간 기본안에서 제외한다.

매주 고객별로 서버·저장·전송비, 결제 수수료, 지원 시간, 세팅 시간을 기록한다. 149,000원 세팅에 2시간이 걸리면 비용 차감 전 시간당 수납은 74,500원이다. 신규 영업·이동·후속 지원 시간까지 포함하면 실제 수익성은 더 낮다.

계속 이용하는 매장의 지원 시간은 온보딩 후 월 30분 이내를 내부 목표로 둔다. 주당 1시간씩 지원해야 하는 39,000원 고객이 늘어나면 신규 설치를 줄이고 반복 원인을 고친다. 초기 세팅 면제 건도 소요 시간은 빠짐없이 기록한다.

## 9. 안 팔릴 때 변경할 기준

| 관찰 결과 | 다음 행동 |
|---|---|
| 서로 다른 적합 매장 30곳 접촉 후 양방향 대화 3곳 미만 | 가격 변경 전에 고객 조건·첫 문구·소개 채널을 바꿔 다음 20곳 확인 |
| 시연 10곳 중 체험 3곳 미만 | 장비·필요성·설치 부담을 분리해 기록; 한 업종과 한 기기 조합으로 좁힘 |

| 종료된 활성 체험 10곳 중 결제 3곳 미만 | 미결제 대표 5명과 이유 확인; 가격만이 원인인지 확인 후 다음 모집군에서 하나의 제안만 변경 |
| 치명적 수업 오류 발생 | 해당 환경 확대·유료 전환을 멈추고 수정 후 현장 재검증 |
| 첫 갱신 대상 8곳 중 갱신 6곳 미만 | 12월 고객 확대보다 이탈 원인과 반복 사용 해결 |
| 11월 말 유료 5곳 미만 | 광고·다지점 기능 투자를 미루고 실제 결제 고객의 공통 문제부터 재정의 |

이 기준은 작은 표본에서 쓰는 운영 신호이지 통계적 검증 결과가 아니다. 가격을 바꿀 때 기존 고객 조건은 유지하고 새 모집군의 가격·기간을 명확히 기록한다.

## 10. 기록할 항목과 오늘 할 일

스프레드시트나 노트 한 행에 다음을 적는다: 매장명 / 지역 / 업종 / 구매 결정권자 / 공개 연락 채널 / 소개 출처 / 첫 연락일 / 현재 수업 방식 / 기기 / 단계 / 다음 행동일 / 시연일 / 체험 시작·종료일 / 실제 주간 수업 횟수 / 첫 결제일 / 다음 갱신일 / 구독 수납 / 세팅 수납 / 지원 분 / 거절·해지 이유 / 공개 사례 동의 여부.

단계는 후보 → 연락 → 대화 → 시연 → 체험 → 결제 → 갱신 또는 종료로 기록한다. 관심 표현·결제 예정·무료 설치는 유료 고객으로 세지 않는다.

오늘 9/18 실행 순서:

1. 기존 파일럿 담당자에게 다음 현장 검증 시간을 요청한다.
2. 직접 방문 가능한 매장 10곳을 찾고 현재 운영 방식·연락 채널을 기록한다.
3. 준비된 기기로 60초 영상을 촬영한다: 휴대폰에서 시작 → TV 표시 → 일시정지 → 다음 운동.
4. 위 첫 연락 문구로 조건에 맞는 3곳에 직접 연락한다.
5. 이번 주 시연 또는 현장 검증 일정 1개를 잡는다.

이 문서는 실행 계획만 작성한 것이며 연락 발송, 고객 모집, 가격 공개, 결제 활성화는 수행하지 않았다.
