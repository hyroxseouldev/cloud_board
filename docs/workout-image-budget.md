# 워크아웃 이미지 용량

워크아웃 하나의 저장 이미지 합계는 100 MB(100,000,000 bytes)까지 허용한다.
정확히 제한값인 경우 저장할 수 있고 1 byte라도 초과하면 저장하지 않는다.
워크아웃에 저장된 카운트다운 이미지를 포함하며 같은 저장소 파일을 여러 슬라이드가 참조하면 한 번만 합산한다.
파일 전송·보관 용량 기준이며 디코딩 후 메모리 사용량과 다르다.

편집 화면은 전체 사용량, 슬라이드별 이미지 용량, 카운트다운 이미지 용량과 초과 안내를 표시한다.
이미지 처리·압축 후 실제 저장할 파일을 계산한다. 조회 실패와 확인할 수 없는 이미지의 크기를
0으로 대체하지 않는다. 저장을 거절해도 기존 저장된 수업과 편집 중인 내용은 보존한다.

서버 `saveWorkout`은 클라이언트가 제출한 합계를 신뢰하지 않고 허용된 버킷의 소유자 경로에 있는
파일 메타데이터로 크기를 확인한다. 임의 외부 URL을 서버에서 요청하지 않는다.
기존 수업의 외부 이미지 URL은 변경하지 않은 경우에만 호환을 유지하며 크기는 미확인으로 남는다.
새 외부 이미지는 검증 가능한 업로드로 교체해야 한다. 기존 Firestore 직접 쓰기를 사용하는
레거시 경로에는 Storage 메타데이터 검증을 적용할 수 없으므로 이 검증을 모든 구버전 쓰기의
완전한 차단이라고 부르지 않는다.

기존 수업을 삭제하거나 일괄 변경하지 않으며, TV 재생·사전 준비 제한과 캐시 정책을 변경하지 않는다.
100 MB 이하라는 이유만으로 TV 준비 시간 내 완료나 재생 무장애를 보장하지 않는다.

이번 변경은 develop 대상이다. 운영 배포와 모바일 업로드는 포함하지 않는다.
기능 코드 반영, 서버 배포, 실제 연결 검증 결과는 각각 PR에 기록한다.
