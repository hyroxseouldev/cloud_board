# STA-13 · STA-15 · STA-16

## 변경

- STA-13: 홈 설정 메뉴의 아바타·이름·이메일 영역에서 프로필로 이동. 하단 중복 메뉴 제거.
- STA-15: 프로필 개인정보처리방침 아래 설치된 앱의 버전과 빌드 번호 표시. CI에서 지정한 Android/iOS 빌드 번호를 package_info_plus로 읽는다. 조회 실패 시 재시도 가능.
- STA-16: 사용자 확인에 따라 **계정 공통 설정**으로 변경. 매장 운영 첫 번째 `워크아웃 설정` 탭에서 화면 문구, 카운트다운, 사운드를 설정. 워크아웃 편집의 기존 설정 버튼 제거.

## 적용 범위와 호환성

`users/{uid}.workoutSettings`에 공통 설정만 병합 저장한다. 프로필·구독 정보와 원본 워크아웃을 일괄 덮어쓰지 않는다. 이미지 경로는 `users/{uid}/brand/workout-settings/`이며 기존 계정 삭제 범위에 포함된다.

공통 설정이 없는 계정은 기존 워크아웃 설정을 유지한다. 설정 화면의 최초 카운트다운 값은 기존 계정 기본값을 가져온다. 처음 공통 설정을 저장한 이후 기존·신규 워크아웃에 적용한다.

수동·예약 수업 시작은 서버에서 공통 설정을 확인한 뒤 재생 세션 스냅샷에 포함한다. 확인 실패 시 이전 설정으로 성공한 것처럼 시작하지 않는다. 진행 중인 원격/로컬 수업의 설정은 고정하여 저장으로 타이머가 재시작되거나 사운드가 바뀌지 않는다. 로컬 미리보기와 편집은 공통 설정이 반영된 상세를 사용한다.

설정 저장 중 중복 요청을 막고, 실패 시 입력을 유지해 재시도할 수 있다. 탭 전환 시 입력을 유지하고 저장하지 않고 나갈 때 확인한다. 계정이 바뀌면 다른 계정 초안을 재사용하지 않는다.
