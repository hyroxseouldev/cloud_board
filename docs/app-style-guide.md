# 앱 스타일 가이드 적용

2026-09-11에 전달받은 Tap Style Guide를 `AppStyle`과 공통 테마에 반영한다. 수치는 Flutter 논리 픽셀 기준이며, Pretendard Bold의 자간 -5%는 `fontSize * -0.05`로 계산한다. 운영 화면의 기존 라벤더 색상과 사용자가 정한 슬라이드·타이머·브랜드 색상은 유지한다.

| 항목 | 태블릿 | 휴대폰 |
| --- | --- | --- |
| Main Text | 44 Bold | 28 Bold |
| Sub Text 1 / 2 / 3 | 32 / 28 / 24 Bold | 24 / 20 / 18 Bold |
| 일반 버튼 / 주요 버튼 최소 높이 | 60 / 80 | 48 / 60 |
| 아이콘 기본 크기 | 30 | 24 |
| 기본 FAB | 100 × 100 | 60 × 60 |

화면의 짧은 변이 600 미만이면 휴대폰 값을 적용한다. 사용자 글자 확대 설정은 그대로 존중하며, 설명·보조 문구는 기존 본문 크기를 유지한다.

- `Button_full`, `Box_full`: 로그인·프로필 폼의 콘텐츠 최대 너비 660. 작은 화면에서는 여백을 제외한 너비로 줄어든다. 입력창은 기본 높이 60을 사용하며, 휴대폰·오류 문구·글자 확대에 따라 높이가 조정된다.
- `Box_2`: 가이드의 카드 기준 너비 540, 태블릿 기본 높이 280. 홈은 사용자 요청에 따라 아이패드에서 가로·세로 모두 3열로 표시하며, 가용 너비에 맞춰 카드를 줄인다. 글자 확대 시 높이를 늘린다.
- `banding`: 사용자 확인에 따라 모서리 둥글기로 적용. 입력·버튼 12, 카드·팝업·시트 24, 태블릿 FAB 40.
- `popup`: 공통 확인·입력 팝업 너비 420, 최소 높이 240. 휴대폰에서는 가용 너비로 줄이며 긴 내용은 스크롤하고 액션 버튼은 접근 가능하게 유지한다. 달력·색상 선택기처럼 전용 배치가 필요한 팝업은 각 위젯의 크기 제약을 유지한다.
- 화면에 직접 지정했던 주요 제목과 제어 요소는 공통 스타일을 사용한다. TV에 표시되는 운동 콘텐츠의 타이포그래피는 이 관리 화면 가이드와 별도로 유지한다.
