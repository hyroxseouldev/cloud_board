글자 확대를 유지하며 긴 라벨은 줄바꿈과 스크롤로 수용한다. 홈 목록 제목은 17/600,
보조 정보는 14, 탭은 12–13/500·선택 600이다.

- 로그인·프로필 폼 최대 폭은 660. 입력창과 버튼은 48 이상이며 내용에 맞게 확장한다.
- 홈은 가용 폭과 글자 배율로 1–2열을 결정한다. 휴대폰 여백 20, 작은 화면 16.
- 입력·버튼 모서리 12, 카드·팝업·시트 24. 반복 목록은 떠 있는 카드 대신 구분선으로 연결한다.
- 확인·입력 팝업 폭 420, 최소 높이 240; 작은 화면은 가용 너비와 스크롤을 사용한다.
- 바탕은 오트, 표면은 따뜻한 흰색, 행동은 세이지다. 입력 경계와 장식 구분선을 구분한다.
- TV 브리핑 글자는 기존 44/28/24 및 w700을 보존한다. 사용자 슬라이드·타이머·센터 색은 바꾸지 않는다.
