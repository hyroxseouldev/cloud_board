## 문제와 목표

Android / TV에서 수업 중 앱을 최소화했다가 다시 실행하면 최신 수업 상태를 확인하는 복귀 화면의 디자인이 깨진다는 사용자 제보. 첨부 화면에서는 흰 배경에 과도하게 큰 빨간 문구와 노란 밑줄이 나타난다. 별도 Android 수업 알림에는 Flutter 기본 아이콘과 긴 상태 안내가 보여 앱과 통일성이 떨어진다.

기존 CloudBoard의 흰 배경·차분한 라벤더·Pretendard를 유지하면서, 복귀 동기화 상태를 작은 스피너와 짧은 문구로 전달한다. TV는 검은 배경을 유지한다.

**단계: develop 구현 및 자동 검증 완료. 실기기 검증 대기.**
**사용자 선택: 1번 중앙 로딩 방향. 추가 요청: 스피너 비율 축소.** 1번 수정본을 선택 방향으로 기록한다.

## 재현 조건

1. Android 컨트롤러 또는 TV 디스플레이에서 수업 실행.
2. 홈 이동 등으로 앱을 최소화 / 백그라운드 전환.
3. 앱 아이콘 또는 수업 알림으로 앱에 복귀.
4. 서버의 최신 수업 상태를 다시 확인하는 동안 로딩 화면 관찰.

OS 버전, 기기 모델, 설치 빌드와 정확한 네트워크 조건은 아직 미확인. 이미지의 촬영일 표기와 별개로 2026-10-01 접수로 기록.

## 선택 방향과 공통 규칙

- 1번 원안의 레이아웃·글씨·여백은 유지하고 Android / TV 스피너만 더 작고 얇게 조정.
- 문구: **수업 동기화 중**. 긴 설명, 붉은 본문, 노란 밑줄 제거.
- 구현 시작 기준: Android 스피너 20–24 logical px / stroke 2, 본문 14sp. TV는 원거리 가독성과 실제 논리 해상도를 확인해 작은 스피너 및 20–24sp 수준 문구로 조정. 시안 이미지의 픽셀 크기를 그대로 복사하지 않는다.
- 색상: accent #77729D, muted #777683, mobile #FFFFFF, TV #050505. 앱 기존 토큰·Pretendard 재사용.
- 복귀 확인 전에는 이전/재생/다음 등 상태 변경 명령을 잠금. 오래된 타이머를 최신 서버 상태로 오인하게 하지 않는다.
- 초기 표시를 짧게 지연해 매우 빠른 복귀에서 깜빡임을 줄이는 방안을 검토. 장시간 대기는 작은 보조 문구, 실패는 명확한 오류 및 **다시 연결 / 상세**로 구분.
- 진행률을 모르면 퍼센트를 표시하지 않음. 애니메이션 감소 설정에서는 정적인 아이콘과 문구 제공.
- TV는 백그라운드에서 로컬 재생·소리를 재개하지 않음. 복귀 후 최신 상태를 확인하고 수업 종료/일시정지/슬라이드 변경까지 반영.

## Android 수업 알림 정리

- Flutter 기본 아이콘 노출 원인: 설치 빌드와 launcher / notification 아이콘 리소스 확인.
- 기존 CloudBoard 모니터·파형 마크를 기반으로 Android small icon 규격에 맞는 단색 리소스 적용 검토.
- 알림 제목은 수업명, 보조 문구는 **웜업 · 일시정지**처럼 짧게. 반복되는 '최근 확인한 수업 · 제어 시 최신 상태 확인' 문구 축소.
- 최신성이 확인되지 않은 상태와 실패 상태는 짧고 사실에 맞게 구분. 정확하지 않은 시간이나 연결 완료를 표시하지 않음.
- 알림 내 이전·재개/일시정지·다음 명령과 서버 확인 동작은 보존.
- 알림의 크기·배치·색상은 OS 및 제조사 템플릿의 제약을 받음. 이미지의 알림은 디자인 의도이며 픽셀 단위 구현 보장이 아님. TV에 휴대폰 알림 UI를 추가하는 범위는 아님.

## 코드 점검 메모 — 원인 확정 전

- `lib/src/app/feature/playback/presentation/widgets/active_class_shell.dart`: 복귀 overlay가 ColoredBox / Text로 구성되어 있고 명시적인 본문 스타일이 없다. 화면 위쪽 계층의 Material / DefaultTextStyle 상속 여부를 우선 점검.
- `lib/src/app/feature/playback/presentation/views/display_mode_screen.dart`: TV 복귀 Text의 색상만 지정돼 있어 공통 복귀 상태 컴포넌트로 정리할 여지가 있다.
- 첨부의 빨간 글씨·노란 밑줄은 Flutter 기본 오류형 텍스트 스타일 노출 가능성이 있으나, 실제 위젯 트리와 실행 빌드로 확인해야 한다.
- `android/app/src/main/kotlin/com/sunmkim/cloudboard/ClassNotifications.kt` 및 `android/app/src/main/res/layout/class_notification.xml`: 긴 subText, notification small icon, custom layout과 시스템 템플릿의 조합 점검.
