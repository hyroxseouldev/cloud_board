## 목표

CloudBoard의 기존 12개 주요 화면을 사용자가 제공한 **Cursor — Style Reference / Warm parchment atelier lit by embers** 방향으로 다시 디자인한다. 운동 센터 대표·매니저·코치가 수업을 찾고 준비하고 운영하는 흐름을 유지하면서, 크림색 바탕·가는 타이포·작은 모서리·얇은 구분선으로 차분한 생산성 도구의 인상을 만든다.

[STA-36](https://linear.app/clyrdev/issue/STA-36)의 기존 안과 비교하는 **별도 디자인 대안**이다. 앱 구현 및 인증·결제·권한·수업 동작 변경은 포함하지 않는다. 검토용 시안 12장(모바일 11장·TV 1장), 확대 갤러리, PDF, 스타일 원문과 생성 프롬프트를 산출물로 관리한다.

문서 내부의 상충 지침은 다음처럼 해석했다.
- 9999px pill 예시보다 반복되는 4px 모서리 기준을 우선한다.
- 축약/잘못된 #26251 표기는 색상 표의 #26251E로 해석한다.
- 그라데이션·광택·유리 효과·장식용 일러스트는 적용하지 않는다.
- CursorGothic·berkeleyMono는 자동 도입하지 않는다. 실제 프로젝트에서 사용 가능한 한국어 글꼴(Pretendard 등)로 400/500 무게와 비례를 맞추고, 숫자에 tabular 기능을 우선 적용한다. 라이선스와 한국어 지원을 확인한 뒤 폰트 확정.
- EB Garamond의 문학적 인상은 참고하되 조작 화면의 한글 라벨에 억지로 섞지 않는다.
- 연결 성공·오프라인·삭제·수업 종료는 브랜드 장식 색과 별도 의미 색상으로 관리한다. 삭제/종료는 붉은색과 확인 절차를 유지.
- Apple/Google 공식 로그인 자산, 사용자 지정 배경·타이머·운동/휴식 색상은 이 테마로 덮어쓰지 않는다.
- TV는 거리 가독성을 우선한다. 관리 화면의 가는 제목 원칙을 큰 타이머에 강제하지 않는다.

## 화면별 리디자인

### 01. 로그인
왼쪽 정렬의 가는 메시지 “수업 준비는 가볍게. 수업에 더 집중하세요.”와 작은 CloudBoard 워드마크. 크림색 여백, 하단 제공자 버튼, 짧은 기존 계정 안내, 주황색 계정 안내 링크로 구성한다. 로그인만으로 무료 체험을 시작하지 않는다. 제공자 버튼은 구현 시 공식 규격으로 교체/검수한다.

### 02. 홈
햄버거·워드마크·우측 검색, 짧은 그리팅, 작은 연결 요약, 폴더 선택과 워크아웃 목록을 유지한다. 썸네일·이름·슬라이드 수·시간·재생·더보기를 얇은 선으로 정렬한다. 추가는 **우하단 FAB** 한 곳, 4px 모서리의 잉크색으로 제안한다. 큰 검색 박스·중앙 시작 카드·전역 바텀 내비게이션을 추가하지 않는다. iPad 기존 3열 및 웹 레이아웃은 별도 반응형 검수.

### 03. 워크아웃 편집
가는 제목·작은 폴더 선택기, 전체 시간 우측 정렬, 드래그 가능한 슬라이드 행. 이름 탭→다이얼로그, 별표로 즐겨찾기 삽입, 목록 끝 슬라이드 추가를 유지한다. 저장됨 문구·연필·실행취소/다시실행 UI를 되살리지 않는다. 변경 없음은 저장 비활성. 예시 합계는 3:40 + 10:00 + 7:00 + 2:00 = 22:40.

### 04. 슬라이드 편집
사용자 배경이 보이는 미리보기와 크림색 설정 영역을 구분한다. 상단 미리 재생·저장, 시간 요약→타이머 바텀시트, 세트 표시 체크박스, 타이머/세트 크기·위치 슬라이더, 가로 스크롤 색상 행을 유지한다. 바닥 4개 섹션은 타이머·배경·소리·즐겨찾기. 선택은 글자/밑줄로 표시하고 불필요한 하단 여백을 줄인다. 시트 **적용→초안 반영→상단 저장** 구분 유지. 이미지 속 색상칩은 사용자 선택값 예시이며 테마 기본값 변경 지시가 아니다.

### 05. 디스플레이 관리
온라인 상태와 화면 표시 스위치를 분리한 평평한 목록. 등록된 장치명·위치·연결 상태·더보기·표시 제어를 함께 읽을 수 있게 한다. 코드/QR 연결 진입은 하단 한 개 액션으로 제공한다. 시안의 2대 온라인/1대 오프라인은 예시 데이터. 오프라인·명령 전송 중·실패·권한 제한 상태를 별도 설계한다.

### 06. 프로필
전체 페이지 유지. 작은 아바타/이름과 프로필 수정 링크, 계정·이용 정보·계정 관리 그룹을 구분선으로 정리한다. 실제 이메일·웹 연결·플랜·연결 가능 수·기간을 표시하며 예시 값을 정책으로 확정하지 않는다. 프로필 수정도 페이지, 로그아웃과 계정 삭제는 분리. 삭제를 주황색 링크와 혼동하지 않게 의미 색상을 구분한다.

### 07. 온보딩
한 단계에 한 주제. 센터 소개 1/3의 역할·센터명·운영 상태를 작은 각진 선택/입력으로 표현한다. 이후 수업 환경→체험 확인/시작→첫 수업 준비로 연결. 필수·선택 항목, 건너뛰기, 입력 보존, 중단 후 재개는 [STA-34](https://linear.app/clyrdev/issue/STA-34) 기준. **1개월 무료 체험은 확인 후 명시적으로 시작**하며 자동 결제·카드 등록 등 미확정 정책을 새로 정하지 않는다.

### 08. 즐겨찾기
전체/즐겨찾기 밑줄 탭, 분류 선택, 작은 썸네일 목록, 채워진 별표와 더보기. 별표 해제와 삭제를 구분한다. 검색/분류/전체 탐색을 보존하고 드로워에 라이브러리와 즐겨찾기를 중복 생성하지 않는다. 독립 관리 화면과 워크아웃에서 진입하는 삽입 모드를 구분하며, 삽입 모드에만 대상 워크아웃과 삽입 액션을 노출한다.

### 09. 매장 운영
워크아웃 기본 설정·대기 화면·예약 재생·원격 관리·운영 리포트의 다섯 목적지를 아이콘+짧은 설명+화살표 목록으로 정리한다. 가상 매출 차트나 신규 지표를 추가하지 않는다. 기존 탭에서 목록형 진입으로 변경하는 탐색 비용을 검토하고, iPad/웹에서는 왼쪽 메뉴+오른쪽 상세를 비교한다.

### 10. 대기 화면 설정
실제 송출 미리보기 아래 문구 표시·매장 이름·문구·위치·이미지 맞춤·전환 효과·배경 이미지 목록을 짧은 폼으로 구성한다. 저장은 상단, 이미지 추가는 한 곳으로 통일한다. 기존 색상/크기/전체 배경/표시 시간/재정렬 설정은 스크롤 또는 상세 영역에 유지. 저장 실패 시 초안을 보존한다.

### 11. 수업 진행
최소화·종료를 분리하고 연결 대상, 현재 수업 미리보기, 큰 일시정지, 이전/다음, 전체 진행, 다음 슬라이드를 선명하게 배치한다. 준비 카운트다운 건너뛰기는 컨트롤러에서 제공. 최소화 후 미니 컨트롤러 복귀, 종료 확인, 일시정지 유지·구간 이동·연결 복구를 유지한다. 타임라인/링의 구간 비율은 생성 시안 예시이므로 실제 시간 데이터로 계산한다.

### 12. TV 송출
검정 배경·운동 안내·타이머·세트·센터명을 거리 가독성 중심으로 정렬한 사용자 슬라이드 예시. 크림색 관리 테마로 일괄 바꾸지 않고 기존 사용자 배경과 게이지 색을 유지한다. 조작 버튼/관리 메뉴/스킵은 표시하지 않는다. 센터 로고 범위는 [STA-17](https://linear.app/clyrdev/issue/STA-17)과 조율한다.

## 보조 화면 및 상태

- 프로필 수정은 페이지, 이름 수정은 다이얼로그, 타이머 상세는 바텀시트로 기존 결정 유지.
- 검색·폴더·색상·이미지 선택기의 선택/취소 의미, 장치 QR 권한/코드 입력/만료/실패 상태 유지.
- 로딩·빈 상태·오류/재시도·오프라인·권한 제한·저장 중/실패·미저장 이탈을 같은 체계로 설계.
- 드로워 닫힘 후 페이지 이동, 뒤로가기 시 홈/검색/스크롤 복원.
- 기능별 동작·하위 화면 기준은 [STA-36](https://linear.app/clyrdev/issue/STA-36)을 이어받고 이 이슈에서 시각적 대안을 비교한다.

## 검토 및 완료 기준

- [ ] 기존 안과 같은 화면별 과업을 수행하면서 새 시각 체계의 장단점을 비교
- [ ] 실제 한국어 폰트·아이콘·공식 로그인 자산으로 옮겨 문구, 줄바꿈, 굵기 검수
- [ ] 주황 링크와 보조 텍스트의 실제 대비 검증; 미달하면 명도 조정하고 밑줄/형태로 의미 보완
- [ ] 320/390px 모바일·가로·iPad 가로세로·웹에서 잘림과 과도한 빈 공간 없이 배치
- [ ] 글꼴 확대·키보드·안전 영역·스크롤·48px 터치 영역 검증
- [ ] 별표 선택, 저장 비활성, 실패/재시도 등 색 외 상태 표현 확인
- [ ] 운동/휴식/타이머 색상과 사용자 배경을 UI 테마에서 분리
- [ ] 수업 진행·종료·스킵·연결 복구의 기존 동작 보존
- [ ] 적용 범위와 공통 토큰을 디자인 리뷰에서 확정한 뒤 구현 이슈로 분리

이미지는 Built-in ImageGen으로 만든 **디자인 검토용 래스터 시안**이다. 실제 실행 앱·정밀 픽셀 스펙·접근성 검증 완료본이 아니다. 일부 글꼴 굵기나 미리보기 비율 등 생성 결과와 토큰 규격의 차이는 구현 전에 정리한다. 모바일 목표는 390×844, TV는 1920×1080 비율이며 실제 생성 픽셀은 다를 수 있다.
