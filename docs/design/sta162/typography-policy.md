번호 배지는 최대 본문 기준이다. 실제 카탈로그의 이전 본문이 102처럼 이미 맞춰져 있었다면 결과의 감소율은 위 최대값 비율과 다르다. 실제 역할별 결과는 before/after metrics.json에서 비교한다. 카드 배치는 카드 영역 자체를 유지하고 내부 패딩을 28→24로 조정한다.

짧은 단일 목록은 남는 높이를 전부 행 사이에 배분하지 않는다. `designSpacing` 0.8/1/1.1/1.2 이상일 때 행간 상한은 각각 32/40/44/48이다. 본문 줄 높이에는 저장된 간격이 계속 반영된다. 일반 헤더 높이 상한은 144→120, 본문 시작 간격은 banner 64→48, editorial 44→36, 나머지 40→32다. 부제 다음 간격은 30이다.

가독성 판정 하한 36px는 그대로다. 내용이 너무 많으면 기존 동작처럼 모든 행을 유지하는 축소 렌더와 읽기 어려움 경고를 함께 제공한다. 24줄을 억지로 36px에 고정해 자르거나 넘치게 하지 않는다. 고정된 stress-studio-24 입력의 변경 전 본문은 16px이며, 새 측정이 이보다 더 작아지지 않는 회귀를 추가했다. 36px 미만 콘텐츠는 저장 가능한 새 구성으로 간주하지 않는 기존 validation을 유지한다.

저장된 `designFontWeight`, `designItalic`, `designSpacing`, 서체·색·내용·순서는 유지한다. banner 제목도 저장된 기울임 선택을 따른다(이전에는 false여도 제목에 기울임이 강제됐다). 새 제공 샘플의 기본값은 별도로 명시된다. 원본 StationD 월~토와 돌파 Brick은 독립 원본 렌더러 경로를 그대로 사용한다.

`slideDesignRendererVersion`은 1→2다. 구 PNG의 재사용 여부와 재저장/복제/라이브러리 자산 재생성은 저장 회귀가 검증한다. 타이머 숫자·세트 크기, 타이머 위치/제외 영역, 출력 해상도와 원본 이미지 데이터는 바꾸지 않았다.

검증: `slide_design_typography_test.dart`, `slide_design_layout_test.dart`, `slide_design_studio_test.dart`, `original_slide_renderer_test.dart`, `slide_design_asset_reuse_test.dart` 합계 **46/46 통과**. 로그 `/tmp/sta162-renderer-tests.log`.

- 새 역할 크기 테스트: 4계열, 카탈로그 12종, legacy v1/v2 × 목록/번호/인터벌 × auto/columns/cards 18조합.
- 저장 굵기 500/900 및 기울임 true/false, 부제·행 보존, 상한 있는 간격, 번호 배지 크기, 고밀도 경고 회귀.
- HD/4K 타이머·세트의 변경 전 절대 좌표 회귀와 실제 콘텐츠 제외 영역 검사.
- 원본 Brick 픽셀 일치와 수정 영역 외 픽셀 보존, studio PNG/미리보기 동일 계획, 렌더 버전 재사용 회귀.

이 결과는 Flutter 자동 검사와 캡처 결과다. 실제 센터 TV의 크기·시청 거리에서 육안 가독성을 측정했다는 의미는 아니다. 해당 실기기 검수 결과는 별도로 기록해야 한다.
