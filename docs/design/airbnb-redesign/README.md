# CloudBoard · 에어비엔비 스타일

STA-36의 12페이지 범위를 기준으로 만든 시안. 모바일 11장과 TV 송출 1장.

- 이슈: https://linear.app/clyrdev/issue/STA-38 (Backlog)
- 갤러리: `index.html` — 확대, 이전/다음, 세로 나열, 원본 저장
- PDF: `cloudboard-airbnb-redesign.pdf` — 한 페이지에 한 화면
- 원본: 번호 순서의 PNG 12장
- 이미지 생성 프롬프트: `prompts.json`

로컬 서버 실행:

```sh
python3 -m http.server 8778 --bind 127.0.0.1 --directory docs/design/airbnb-redesign
```

브라우저에서 http://127.0.0.1:8778 을 연다.

## 검토 기준

흰 배경, 검정 주요 액션, 작은 코랄 포인트를 공통으로 사용한다. 홈의 목록·앱바 검색·우하단 FAB, 별표 즐겨찾기, 현재 편집/운영 하단 메뉴 구조를 유지한다. 온보딩은 선택된 목적 선택 3번 방향을 따른다.

이 파일들은 생성형 디자인 시안이며 앱 구현이나 실행 캡처가 아니다. 전체 12페이지의 대표 상태를 다루며 모든 하위 탭·다이얼로그를 별도 그림으로 제공하지 않는다. 반응형·접근성·실제 기능 검증은 구현 단계에서 수행한다. 타이머 원호와 타임라인 비율은 실제 시간에 맞춰 계산해야 한다. 사용자 지정 타이머 색과 사진은 앱 UI의 색상 토큰과 별개다. 시안 데이터는 예시다.

PNG 원본 12장과 PDF는 STA-38에 첨부했고, 본문에 페이지별 이미지를 순서대로 배치했다.
