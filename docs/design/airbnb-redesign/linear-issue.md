## 목적과 범위

[STA-36](https://linear.app/clyrdev/issue/STA-36)의 **전체 12페이지 범위**를 기준으로, 사용자가 제공한 Airbnb 스타일 레퍼런스를 CloudBoard 전반에 적용하는 리디자인이다. 모바일 11장과 TV 송출 1장을 하나의 일관된 방향으로 제작했다.

**현재 단계: 이미지 시안 검토 / Backlog.** 아래는 생성형 디자인 시안이며 실제 앱 실행 캡처나 구현 완료 결과가 아니다. 각 페이지의 대표 상태를 제시하며, 모든 하위 탭·다이얼로그·오류 상태를 별도 이미지로 제작한 것은 아니다.

## 공통 디자인 방향

- 흰 배경과 짙은 검정, 얇은 구분선, 절제된 회색 보조 텍스트.
- 주요 버튼은 검정, 코랄은 FAB·선택 상태·작은 브랜드 포인트에 제한적으로 사용한다.
- 목록 자체의 큰 배경과 그림자를 줄이고 사진·간격·타이포그래피로 정보를 나눈다.
- CloudBoard 이름과 한글 가독성을 유지한다. Airbnb 로고나 전용 글꼴은 복제하지 않는다.

수치는 구현 출발점이다. 작은 아이콘도 충분한 터치 영역을 확보하고, 글꼴 확대와 화면 크기에 맞춰 조정한다.

## 유지할 동작과 후속 검토

- 모바일 홈: 검색은 우측 앱바 액션, 워크아웃은 간결한 목록, 추가는 우하단 FAB.
- iPad의 기존 3열 그리드와 웹 최대 너비 정책은 유지하고 별도 반응형 검수를 한다.
- 드로워의 즐겨찾기는 별표와 현재 명칭을 유지한다. 메뉴 이동 전에 드로워를 닫는다.
- 현재 하단 내비게이션과 부드러운 전환을 유지한다. 이번 시안은 라우팅 구조 변경을 요구하지 않는다.
- 이름 수정 다이얼로그, 저장 아이콘 활성/비활성, 타이머 설정 바텀시트 등 합의된 편집 동작을 유지한다.
- 세트 글씨 크기·세로 위치 조절과 기본 위치 7%, 가로 스크롤 색상 선택을 유지한다. 타이머 색상은 사용자 콘텐츠이며 앱 UI의 코랄 포인트와 별개다.
- Firebase 기반 센터 정보·문자 인증·온보딩과 1개월 무료 체험 정책은 그대로 연결한다. 시안의 체험 날짜·센터·수업 데이터는 예시다.
- 타이머 원호·타임라인의 비율은 시각적 예시이며 구현 시 실제 시간값으로 계산한다. 실제 대비·VoiceOver·큰 글꼴 검증은 구현 단계에서 수행한다.
