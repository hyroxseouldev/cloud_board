# STA-146 · STA-147 · STA-148 구현 검토

2026-10-13 · final result: passed (로컬 위젯 렌더링 및 자동 회귀 범위)

기준은 `references/proposed-slide-create.png`, `references/proposed-slide-editor.png`, 루트 `design.md`의 v5 Oat Sage 토큰과 각 이슈의 보존 흐름이다. 두 시안은 각각 853×1844이며 390×844로 정규화해 실제 390×844 논리 픽셀 캡처와 함께 열어 비교했다. 실제 캡처는 프로덕션 화면·컨트롤러와 로컬 저장소 fixture를 사용한다. 폰트는 앱에 포함된 Pretendard, DPR은 2다.

STA-148에는 별도 선택 이미지가 제공되지 않았다. 새 시안과 일치한다고 주장하지 않고 기존 v5 테마, 이슈의 수업 구성 위계, 실제 위젯 동작을 기준으로 검토했다. 네이티브 상태 표시줄이나 소프트 키보드를 그림으로 만들지 않았다. 키보드 캡처의 하단 빈 공간은 240 논리 픽셀 viewInsets 예약 영역이다.

## 발견하고 수정한 문제

1. **P2 · 키보드+2× 글자+저장소 오류:** 남은 영역 103px보다 내부 탭이 높아 17px overflow가 발생했다. 극소 높이에서는 탭과 설정을 함께 스크롤하고, 키보드가 열린 동안 중복 제목을 제거했다. 해당 조합 회귀가 통과했다.
2. **P2 · 큰 글자 저장 오류:** 상세 오류와 요약 상태가 고정 영역을 중복 차지했다. 큰 글자에서는 상세 안내를 설정 스크롤 영역으로 옮기고 프리뷰 높이를 제한했다. 제목·상태·재시도는 유지하며 설정과 오류 전문을 스크롤할 수 있다. 2× 오류 상태에서 실제 ‘편집’ 텍스트까지 스크롤해 hitTestable임을 확인하고 재시도 버튼의 활성 상태도 검증했다.
3. **P2 · 사용량 재조회 실패:** Riverpod의 이전 성공값이 남으면 조회 실패 뒤에도 생성 CTA가 활성일 수 있었다. 조회 중/실패/잔여 0회에는 세 생성 경로의 CTA를 비활성화한다. 이전 값이 남은 실패→새로고침 성공을 별도 회귀로 확인했다.
4. **P2 · 빈 디자인 응답:** 빈 목록이 성공처럼 끝나던 경로에 명시적인 빈 결과 오류를 넣었다. 입력은 유지되고 다음 재시도가 정상 제안을 반환하는 테스트를 추가했다.
5. **접근 가능한 순서 변경:** 드래그 외에 슬라이드 메뉴의 위로/아래로 이동을 제공한다. 경계 항목 비활성화, 순서 변경 후 미저장 상태, 저장된 최종 순서를 검증했다.

독립 검토에서도 P0/P1은 발견되지 않았다. 추가 검토 의견인 생성 방식 칩의 밀도는 세 방식 직접 접근과 beta 상태 보존을 위한 의도된 차이로 기록했고, 큰 글자 오류의 다음 동작 접근은 실제 스크롤 assertion으로 검증했다. 현재 검토 범위에서 미해결 P0/P1/P2는 없다. P3: 320px에서 2× 글자일 때 ‘라이브러리’ 탭이 두 줄로 줄바꿈된다. 축소하거나 생략하지 않아 레이블을 읽고 선택할 수 있다.

## 동작 및 검증

- `수업에 추가`는 현재 수업 초안으로 결과를 반환한다. 상위 수업 저장과 분리했고 빠른 중복 추가를 막는다. 템플릿/직접 수정은 생성 요청을 하지 않는다.
- `타이머 반영`은 슬라이드 초안만 변경한다. 저장 중에는 중복 저장을 막으며 성공 응답 뒤에만 `저장됨`을 표시한다. 실패 후 초안과 값이 유지된다.
- 로컬 연습은 TV 세션을 시작/수정하지 않는다. 연습·다음·종료·완료 fixture에서 TV transport 호출 수 0을 확인했다. TV 시작 전 기존 저장/대상 선택 경로를 유지했다.
- 주요 버튼과 드래그 영역은 최소 48px이며 텍스트 레이블, 선택 상태, 저장 상태 live region을 제공한다. 작은 화면·2× 글자·가로·태블릿은 위젯 회귀로 확인했다. 실제 VoiceOver/TalkBack 및 실기기 키보드 검증은 이번 실행에 포함되지 않는다.
- 1차 전체 관련 회귀: 11개 테스트 파일 + 캡처 파일 **132/132 통과** (`/tmp/sta146-148-final.log`).
- 마지막 보정 후 AI/슬라이드/타이머 6개 테스트 파일 + 캡처 **73/73 통과** (`/tmp/sta146-148-final-followup.log`).
- 최종 20장 캡처 fixture **3/3 통과**, 경고 없음 (`/tmp/sta146-148-capture-final.log`). 이후 큰 글자 스크롤 assertion과 전체 suite에서 드러난 기존 디자인 섹션 테스트의 프레임 대기 수정을 합쳐 **8/8 재통과** (`/tmp/sta146-148-final-regression.log`). 재현: `flutter test --no-pub tool/sta146_148_capture_test.dart`.

최종 통합 analyze·전체 테스트·플랫폼 빌드는 root 통합 검증 결과를 따른다. 계정/결제/TV 서버에 쓰지 않았으며 실기기 테스트는 사용자가 추후 수행하기로 한 범위를 따른다.
