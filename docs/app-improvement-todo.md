## 문서 목적

사용자 피드백을 실제 개발 작업 단위와 완료 조건으로 정리한다. 기존에 저장된 운동과 슬라이드는 업데이트 후에도 정상적으로 열리고 재생되어야 한다.

## 확정된 제품 기준

- 타이머 색상은 타이머의 게이지 색상을 의미한다.
- 운동과 휴식의 게이지 색상을 각각 설정한다.
- 운동과 휴식의 시간 텍스트 색상도 각각 설정한다.
- 색상은 컬러 피커와 HEX 코드로 입력할 수 있다.
- 세트 표시는 `3/5세트` 형식을 사용하며, 남은 세트 수와 전체 세트 수를 의미한다.
- 타이머 표시 여부는 슬라이드별로 설정한다. 타이머를 숨겨도 시간과 슬라이드 진행은 유지한다.
- 타이머는 `숫자 + 게이지`, `숫자만`, `안 보임` 중 선택한다. 세트 표시는 별도 ON/OFF로 설정하며 타이머 표시 여부와 독립적으로 작동한다.
- 스탠바이 이미지 전환 효과는 `없음`, `페이드`, `슬라이드`를 제공한다.
- 새 슬라이드 기본 제목은 `새 운동 1`, `새 운동 2` 형식을 사용한다.
- 슬라이드 설정은 별도의 하위 페이지에서 편집한다.
- 변경 사항은 저장 버튼을 눌렀을 때 일괄 저장한다.
- 저장하지 않은 변경 사항이 있는 상태에서 페이지를 나가면 확인창을 표시한다.

## 구현 및 검증 결과 — 2026-09-10

위 개발 항목은 모두 구현했고 테스트 체크리스트는 자동 테스트 기준으로 확인했다. 실제 계정의 Firebase 업로드·태블릿·TV 설치 후 동작은 별도 실기기 확인이 필요하다. 이번 작업에서는 스토어 업로드, 호스팅 배포, 기기 설치를 수행하지 않았다.

### 사용 경로

- 워크아웃 편집 → 슬라이드 또는 `⋯ → 수정` → 독립 편집 페이지 → 저장.
- 프로필 메뉴의 `매장 운영` → `브랜드·대기 화면` → `대기 화면 이미지·전환 설정`에서 별도 설정 페이지로 진입한다.
- 슬라이드 경로: `/editor/:id/slides/:moduleId`.
- 매장 운영 → 브랜드·대기 화면 탭 → 대기 화면 이미지·전환 설정.
- 대기 설정 경로: `/operations/standby`.
- 슬라이드 편집은 로컬 초안이며, 저장 버튼으로 일괄 저장한다. 이미지도 선택 시에는 로컬 데이터로 유지하고 저장할 때 업로드한다.
- 새 워크아웃 이름을 아직 입력하지 않았으면 슬라이드 저장 중 이름을 입력할 수 있어, 편집 내용을 버리고 부모 화면으로 돌아갈 필요가 없다.
- 목록의 복제·삭제·순서 변경도 저장 전까지 로컬 초안으로 유지된다.

### 데이터 호환성과 이미지 보존 정책

- 색상은 선택 필드 4개에 `#RRGGBB`로 저장한다. 기존 `timerColorValue`와 기본 운동/휴식 색상을 계속 읽는다. 기존 색상을 수정하지 않았다면 마지막 3초 강조 동작도 유지한다.
- 기존 시간 데이터는 초 단위 그대로 유지한다. 편집 UI에서만 `mm:ss`로 변환한다.
- 기존 대기 이미지 목록은 유지하며, 표시 시간 누락 시 이미지당 1분, 전환 효과 누락 시 페이드를 사용한다.
- 복제된 슬라이드·워크아웃과 실행 중인 세션이 같은 이미지 URL을 참조할 수 있다. 새 이미지는 새 파일 경로로 업로드하며, 슬라이드/워크아웃 삭제나 이미지 교체 시 원본 파일을 즉시 삭제하지 않는다.
- 따라서 사용하지 않는 이미지가 Storage에 남을 수 있다. 실제 파일 정리는 전체 참조를 확인하는 별도 관리 작업에서 수행해야 한다.

### 검증

- `flutter analyze`: 문제 없음.
- `flutter test`: 전체 58개 통과.
- `flutter build apk --debug`: 성공.
- `flutter build web --release`: 성공.
- 테스트 해상도: 390×844, 800×1280, 1280×720, 1920×1080. 재생 및 대기 화면의 레이아웃 오버플로 검사 포함.
- 추가 검증: 기존 데이터/세션 직렬화, HEX 왕복·오류값, 시간 입력·복구, 숨김 중 진행, 운동/휴식 세트·색상, 새 워크아웃 하위 편집, 저장 실패·재시도, 경로 이동·뒤로 가기 확인, 복제·삭제 확인, 폴더 생성·중복·취소, 이미지 순서·시간·오류·3가지 전환.
- Android 빌드는 성공했으나 기존 Firebase 플러그인의 향후 Kotlin Gradle Plugin 호환성 경고가 남아 있다. 이번 기능의 빌드를 막는 오류는 아니다.
